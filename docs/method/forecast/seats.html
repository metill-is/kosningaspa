1.4 From vote shares to seats

How kosningaspá turns kjördæmi votes into Alþingi's 63 seats: D'Hondt in each kjördæmi, nine adjustment seats by national D'Hondt over the lists with at least 5%, each placed where the list's next quotient, as a share of the kjördæmi's valid votes, is largest; the two layouts; the 2021 count traced step by step; what folding lists into Annað does; and how the allocator is tested against every official seat since 2016.

The plain picture

Alþingi, Iceland's parliament, has 63 seats in six kjördæmi (constituencies). A party stands as a list in each kjördæmi, under its letter (the letters are in chapter 0.2). Kosningaspá allocates the seats in each posterior draw of the kjördæmi votes, with one function, calculate_seats() in R/election_utils.R, in two stages:

  • 54 kjördæmi seats. In each kjördæmi, its constituency seats go by D'Hondt over the lists that ran there. A list needs no national threshold for these.
  • 9 adjustment seats. These go one at a time to the list with the largest national D'Hondt quotient, its national votes divided by the seats it already holds plus one, among the lists with at least 5% of the national vote. Each is placed in the kjördæmi where that list's next quotient, as a share of the valid votes cast there, is largest, among the kjördæmi that still have an adjustment seat to give.

On the official results, the function reproduces every seat of the 2016, 2017, 2021 and 2024 elections, and in 2021 it places each adjustment seat where Alþingi's own results page does. In the forecasts of the backtest harness (harness/ and R/harness/), the lists are the parties the polls report, and Annað, the residual of small lists, can win no seat. The 2024 forecast let Annað run as an ordinary list.

The rules, as the code applies them

Allocation
  1. Kjördæmi seats. For each kjördæmi $k$ with $c_k$ constituency seats: give a seat to the list with the largest quotient $v_{ik}/(s_{ik}+1)$, where $v_{ik}$ is list $i$'s votes there and $s_{ik}$ its seats so far, and repeat $c_k$ times.
  2. Threshold. A list takes part in the adjustment seats only if its national share $V_i/\sum_j V_j$ is at least 5%, where $V_i = \sum_k v_{ik}$ and the sum over $j$ runs over every row, the small lists included.
  3. Which list. For each of the 9 adjustment seats in turn, give it to the list over the threshold with the largest $V_i/(S_i + 1)$. Here $S_i$ counts all of list $i$'s seats so far, kjördæmi and adjustment.
  4. Where. Place that seat in the kjördæmi $k$ that maximises $v_{ik}/(s_{ik}+1)\,/\,\sum_j v_{jk}$, the list's next quotient there as a share of that kjördæmi's valid votes, among the kjördæmi with an adjustment seat still free. Here $s_{ik}$ includes adjustment seats already placed.

A list passed as ineligible (section The allocator in code) takes part in neither step 1 nor step 3, but its votes still count in $\sum_j V_j$ in step 2 and in $\sum_j v_{jk}$ in step 4. An exact tie goes to whichever list or kjördæmi comes first in the code's sorted input (section The allocator in code).

The 2016, 2017 and 2021 elections were counted under Lög um kosningar til Alþingis nr. 24/2000, and the 2024 election under Kosningalög nr. 112/2021, which replaced it on 1 Jan 2022. calculate_seats() reproduces the rule as it was applied in those four elections: that is what the test against every official seat shows (section How it is tested). The acts' text has not been read against the code for these notes, so cases the four elections never met, such as exact ties, rest on the code alone.

For 2024 one constituency seat moved from Norðvestur to Suðvestur. A forecast must use the layout in force at the election it forecasts. calculate_seats() defaults to the 2024 layout, so a forecast of 2021 has to pass layout_for("2021-09-25") explicitly. Passing the wrong layout raises no error: the function checks only that the draw's kjördæmi names match the layout's.

The allocator in code

calculate_seats(draw, layout = seats_tibble(), ineligible = character(0)) takes one draw as rows of flokkur, kjordaemi and votes. It returns, per list and kjördæmi, seats (all seats) and kjordaemi_seats (seats before adjustment).

  • Ineligible lists win no seat in either stage. Their votes still count as valid votes, in the 5% threshold and in the shares that place the adjustment seats. The harness passes "Annað", and seat_draws() does so by default; e1910f6 gives the reason only as "so Annað wins no seat in a forecast". The 2024 forecast's copy (below) has no such argument, so there Annað ran as an ordinary list and could win seats. Whether any of its draws gave Annað a seat is not measured here.
  • Ties. which.max() takes the first maximum, so the function sorts its input by kjördæmi and list first. A tie then always breaks the same way, whatever order the rows came in. Integer vote draws can tie.
  • History. Since e1910f6 (24 Oct 2026, PR #4) the function runs the same two stages as the 2024 forecast's copy, with the 2024 layout as its default and the ineligible argument added. Before that, the live R/election_utils.R had the 2013–2021 layout and a different adjustment rule, built on seat entitlements of each eligible list's share times 63. The 2024 forecast used neither: R/archive/predict_seats.R carries its own copy, with the 2024 layout and the same two stages but no ineligible argument.
  • Older helpers. dhondt() and jofnunarsaeti() in the same file are not part of this allocator, and nothing calls them; R/archive/process_predictions.R defines and uses its own copies.

Traced

From draws to seat distributions

A forecast gives, per posterior draw, integer votes for each list in each kjördæmi (y_pred_constituency, chapter 1.3). Running an allocator on each draw turns them into a joint distribution of seats. From that come each party's seat distribution and the probability that a set of parties holds a majority, at least 32 of 63 seats.

  • The harness does this in R/harness/scores.R: seat_draws() runs the allocator per draw with Annað ineligible by default, majority_prob() counts draws at 32 seats or more, and seat_scores() scores the seats against a result.
  • The live forecast scripts write the seat draws with R/predict_seats.R, which runs calculate_seats() once per draw with Annað ineligible and writes seats_draws.parquet (9031952, 10 Nov 2026). R/process_seats_draws.R, R/make_meirihlutar_plots.R and R/make_new_prediction_plots_seats.R read that file. For the 2024 forecast it was written by R/archive/predict_seats.R, with Annað as an ordinary list; that script is kept as the record of the published rules. Run on the 2024-11-30 forecast's draws, the two give the same seats in every draw, party and kjördæmi (9031952). PR #16 fixed two of the plots built from it. The seat plot (make_new_prediction_plots_seats.R) now draws the posterior's own probabilities (aaf0aa1). In the majority plot, the coalition labelled DFS now sums D, F and S where it had summed D, M and S (6ecf13d), and the side table is sorted as the plot is (bcd1ea6).

What folding into Annað does

The forecast models the parties the polls report, so any list the polls do not name is folded into Annað, which in the harness wins nothing. On the official results that costs seats only when a folded list was big enough to win them:

If none of the folded lists won a seat, folding them into an ineligible Annað changes no seat: the other lists' quotients and each kjördæmi's valid votes stay as they were, and no folded list was ever the largest quotient (exact ties aside). That is Claude's argument from the rule, and the 2017, 2021 and 2024 rows bear it out. When a folded list did win, its seats go to others, and those can shift adjustment seats between the other lists. In 2016 they did. Björt framtíð's constituency seats in Reykjavík Norður and Suðvestur went to V and to Viðreisn (C); C's Suðvestur adjustment seat then went back into the national pass with Björt framtíð's two, and S, D and V took one each. No other list lost a seat in any kjördæmi.

The poll data have no Björt framtíð category: its votes are part of Annað, so even a forecast that got every vote right would have given its four 2016 seats to others. Whether the planned v2 forecast should split Björt framtíð out of Annað is open in its design (chapter 3.1, What is open; 4.2, planned).

How it is tested

  • Every official seat. tests/harness/test-truth.R runs calculate_seats() on the unfolded lists of each election, with no ineligible list. It reproduces every official seat of 2016, 2017, 2021 and 2024, Björt framtíð's four in 2016 included, and each layout's kjördæmi totals.
  • 2021 placement. The same file checks each 2021 adjustment seat against Alþingi's results page, which lists the members elected after the recount of Norðvestur's votes (harness/sources/seats_2021_official.csv, counted from a capture of that page). Hagstofa's two 2021 seat tables disagree with that page in six list × kjördæmi cells between them: the older spreadsheet in all six, the current table KOS02019 in four. Both give S no seat in Suður, where D'Hondt on Hagstofa's own votes gives S a constituency seat, which the adjustment step cannot take away. harness/truth/README.md documents this, and the tests do not use those tables.
  • The rules for ineligible lists. tests/harness/test-seats.R checks that:
    • the 2013–2021 layout holds 63 seats and layout_for() returns the 2013–2021 layout for 2017 and the 2024 layout for 2024, and refuses 2013 (the 2024 layout is checked in test-truth.R, whose allocator test also compares each kjördæmi's official seat total with the layout's);
    • an ineligible list wins no seat while the others still fill 63;
    • its votes count in the 5% threshold;
    • its votes count in the shares that place the adjustment seats.

The seat tests in test-truth.R compare against build_truth(), which rebuilds the official results from sheets in the harness's git-ignored snapshot (its frozen, checksummed copy of the input data; harness/README.md), so they skip without it. One of them checks that the committed harness/truth/elections_official.csv equals that rebuild; that committed file is what the scripts behind this chapter read, so a reader without the snapshot can rerun the 2021 check with d_2021.R. The four tests in test-seats.R need no snapshot.

What is open

Open
  • Folding. In the harness a list the polls do not name wins nothing. That matters whenever such a list would win a seat: over 5% nationally, or strong enough in one kjördæmi for a constituency seat, which needs no threshold. Björt framtíð's 2016 seats are the example.
  • No seat distribution here. The chapter shows no forecast's seat distribution: it works from official results only, and no forecast has been fitted for these notes.
  • Layouts. layout_for() knows four election dates. The next election's layout has to be added before it is forecast.
  • The acts' articles have not been read against the code for these notes. Only the official results have been checked.
